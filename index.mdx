Denick is a free, open REST API that resolves Hypixel player nicknames to their real Minecraft username and UUID. No authentication, no sign-up, and no API key required — just send a nickname and get back the real player identity in milliseconds.

## Get Started in Three Steps

<Steps>
  <Step title="No Setup Required">
    The API is completely open — no API key, account, or authentication is needed. You can start making requests right away.
  </Step>
  <Step title="Make a Request">
    Send a `GET` request to the `/denick` endpoint with the nickname you want to look up:

    ```bash Example Request
    curl "https://hy.star.lat/denick?nick=yourNick"
    ```
  </Step>
  <Step title="Use the Response">
    Read the `realName` and `realUuid` fields from the JSON response to identify the real player behind the nickname:

    ```json Example Response
    {
      "nick": "yourNick",
      "realName": "unsplash",
      "realUuid": "47602aa7-ea3f-48b2-ab51-8411d4a75cee"
    }
    ```
  </Step>
</Steps>

<Note>
  Denick enforces a rate limit of **100 requests per 60-second window** per client. Stay within this limit to ensure uninterrupted access for all users.
</Note>
