The root endpoint `/` on the Denick API is a lightweight status check that responds with a `302 Found` redirect to the documentation at [docs.star.lat](https://docs.star.lat). A successful redirect confirms the API process is running and reachable, but it does not check the database. Use [`GET /health`](/api/health) to verify database connectivity.

## Request

```http
GET https://hy.star.lat/
```

This endpoint takes no query parameters and no request body.

### Example request

```bash cURL
curl -i https://hy.star.lat/
```

## Response

A `302 Found` response with a `Location` header pointing to the documentation site.

```http Response
HTTP/1.1 302 Found
Location: https://docs.star.lat
```

<Note>
  Most HTTP clients follow the redirect automatically. Pass `-i` to inspect the response, or `-L` to follow it, when using `curl`. This endpoint does not confirm database connectivity; use [`GET /health`](/api/health) for that.
</Note>

<Tip>
  Requests to `/` count against the rate limit of 100 requests per 60-second window, the same as every other endpoint.
</Tip>
