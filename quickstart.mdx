---
title: "Denick Quickstart: Your First Hypixel Nickname Lookup"
sidebarTitle: "Quickstart"
description: "Make your first Denick API call to resolve a Hypixel nickname to a real Minecraft username and UUID — no sign-up or API key required."
---

Denick requires no authentication or sign-up. You can start resolving Hypixel nicknames immediately by sending a GET request to the public API.

<Steps>

  <Step title="Choose a nickname to look up">
    Pick any Hypixel in-game nickname you want to resolve. Nicknames follow standard Minecraft username rules — they must be between 1 and 16 characters long and contain only letters, numbers, or underscores.

    <Note>
      Nicknames must match the pattern `^[a-zA-Z0-9_]{1,16}$`. Passing a nickname that contains spaces, special characters, or exceeds 16 characters will return a `400 Invalid nickname format` error.
    </Note>
  </Step>

  <Step title="Send your first request">
    Call `GET /denick` with the `nick` query parameter set to the nickname you want to look up. Choose the language that fits your workflow:

    <CodeGroup>

      ```bash curl
      curl "https://hy.star.lat/denick?nick=thealfie381"
      ```

      ```javascript JavaScript
      const res = await fetch('https://hy.star.lat/denick?nick=thealfie381');
      const data = await res.json();
      console.log(data);
      ```

      ```python Python
      import requests
      r = requests.get('https://hy.star.lat/denick', params={'nick': 'thealfie381'})
      print(r.json())
      ```

    </CodeGroup>
  </Step>

  <Step title="Read the response">
    A successful lookup returns HTTP `200` with a JSON body containing three fields:

    ```json Response
    {
      "nick": "thealfie381",
      "realName": "unsplash",
      "realUuid": "47602aa7-ea3f-48b2-ab51-8411d4a75cee"
    }
    ```

    | Field | Description |
    |---|---|
    | `nick` | The nickname you queried — echoed back exactly as supplied. |
    | `realName` | The player's real Minecraft username linked to that nickname. |
    | `realUuid` | The player's Minecraft UUID in standard hyphenated format. |

    <Tip>
      Denick caches resolved nicknames for up to two hours and holds up to 10,000 entries in memory. Cache entries are invalidated automatically whenever a nickname changes in the database, so you always receive fresh data.
    </Tip>
  </Step>

  <Step title="Handle errors">
    Most lookup failures fall into one of two categories:

    - **404 — Not found.** The nickname exists in the correct format but has no match in the database. The response body will read `{ "error": "Nickname thealfie381 not found" }`.
    - **400 — Invalid format.** The nickname you supplied does not satisfy the 1–16 character alphanumeric-underscore rule. The response body will read `{ "error": "Invalid nickname format" }`.

    See the [Errors page](/api/errors) for the complete list of status codes and their meanings.
  </Step>

</Steps>
