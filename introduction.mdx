On Hypixel, certain game modes allow players to disguise their identity behind a randomly assigned nickname, hiding their real Minecraft username from opponents and spectators. While this adds a layer of anonymity during gameplay, there are many legitimate use cases — from moderation tools to statistics trackers — where resolving a nickname back to the real player behind it is essential. Denick makes that resolution simple: send a nickname, get back the real username and UUID.

## Key Features

## Base URL

All API requests are made to the following base URL:

```plaintext Base URL
https://hy.star.lat
```

## How It Works

When you submit a nickname, Denick first checks its in-memory LRU cache. If a fresh result is available — cached entries are valid for up to two hours and invalidated in real time when a nickname changes — Denick returns it immediately without a database round-trip. If the nickname isn't cached, Denick queries its database, stores the result in the cache for future requests, and returns the real username and UUID to you. The entire flow is transparent: you always receive a single, consistent JSON object regardless of whether the result came from cache or the database.
